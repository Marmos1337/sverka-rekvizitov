# Сверка реквизитов

Учебный прототип: проверка письма и счёта поставщика на подмену платёжных реквизитов до оплаты. Для бухгалтера малого и среднего предприятия.

Демо: https://marmos1337.github.io/sverka-rekvizitov/

Приложение работает в браузере, без сервера. На вкладке «Проверка» можно нажать четыре демо-сценария. Все контрагенты и реквизиты синтетические, реальные данные не используются и никуда не отправляются.

Проект команды KIB-05, ДЗ «Кибербезопасность», НИУ ВШЭ, 2026. Собран в Claude Code (Claude Opus 5.5) в режиме вайб-кодинга.
